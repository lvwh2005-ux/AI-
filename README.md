AI Screen 是一个面向 Windows 的桌面屏幕工具。按下快捷键，选择一个窗口或框选一块区域，即可复制、标注、置顶贴图、提取文字，或把选区交给 AI 翻译、解释和回答问题。项目也提供长截图和录屏入口。

基于 **Electron + TypeScript + React** 开发，采用 **MIT License**。

> 当前版本：**0.18.0-test.3（测试版）**。提供 Windows x64 安装版与解压版；默认使用演示模式，真实 AI 功能需要自行配置服务。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 区域与窗口截图 | 快捷键唤起，悬停预选窗口，单击选择窗口或拖动框选，复制选区图片 |
| 图片标注与贴图 | 画笔、箭头、矩形、文字、撤销，以及独立置顶贴图 |
| 滚动长截图 | 手动滚动拼接、预览与缩放、标注、复制及 PNG 导出；提供实验性自动滚动 |
| 屏幕录像 | MP4 / WebM，暂停与继续，可选系统声音和麦克风，录制后预览并另存 |
| 文字识别 | 支持 Windows 本地 OCR 和视觉模型识别 |
| AI 翻译与提问 | 选区翻译、内容分析、追问、自定义动作、流式回复与 Markdown 显示 |

## 下载与安装

### 系统要求

- **Windows 10 / 11 x64**，即 Intel / AMD 64 位系统。
- 运行打包好的程序无需安装 Node.js、npm、Python 或额外的 FFmpeg。
- 本地 OCR 依赖 Windows 对应的 OCR 语言组件；AI 功能依赖自行配置的视觉服务。

本项目目前仅提供 Windows x64 发行包。

### 选择下载文件

打开仓库右侧的 **Releases**，进入对应版本，在 **Assets** 中选择：

| 文件 | 适合谁 | 使用方式 |
| --- | --- | --- |
| `AI-Screen-0.18.0-test.3-win-x64-setup.exe` | 希望安装到电脑的用户 | 运行安装向导，安装后从桌面或开始菜单打开 |
| `AI-Screen-0.18.0-test.3-win-x64.zip` | 希望解压即用的用户 | 全部解压，打开其中的 `AI Screen.exe` |
| `AI-Screen-0.18.0-test.3-source.zip` / `Source code` | 希望修改源码的开发者 | 安装开发依赖后运行或构建 |
| `SHA256SUMS.txt` | 希望核对下载文件的用户 | 与本地计算的 SHA-256 比较 |

使用解压版时，必须保留同目录的 `resources`、`locales`、DLL 等文件。移动或分享时移动整个程序目录，或直接分享原始 ZIP。

**不要只复制 `AI Screen.exe`，也不要在压缩软件内直接运行它。** 仓库的 **Code → Download ZIP** 下载的是源码，不能直接双击运行。

当前版本没有代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。请先确认下载来源，需要时核对发布的 SHA-256；组织策略阻止运行时，请联系管理员。

## 快速上手

1. 启动程序，默认进入**演示模式**，可以先体验截图、标注、贴图、长截图和录屏。
2. 按 **`Alt+A`** 唤起截图，单击选择窗口，或拖动鼠标框选区域。
3. 在工具栏中选择复制、标注、固定、翻译或 AI 操作。真实翻译与提问需先完成下方的 AI 配置。
4. 长截图和录屏可以从主窗口或截图模式入口进入。
5. 关闭主窗口后，程序仍会驻留系统托盘。彻底退出或更新前，请从托盘菜单选择退出。

### 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Alt+A` | 唤起截图，可在设置中修改 |
| `Esc` | 退出当前普通截图 |
| `Ctrl+Alt+Space` | 录屏时暂停 / 继续 |
| `Ctrl+Alt+Enter` | 完成长截图或录屏 |
| `Ctrl+Alt+Esc` | 取消长截图或录屏 |

快捷键被其他软件占用时，可以修改配置，或使用主窗口、工具条和托盘入口。

### 长截图与录屏

**长截图**：框住滚动正文，尽量避开固定标题和侧栏。手动滚动时，每次移动不超过约半个选区高度，留出重叠并稍作停顿。完成后检查接缝和末尾，再复制或保存。

**录屏**：框选范围后选择 MP4 或 WebM，按需启用系统声音或麦克风，再开始录制。声音默认关闭；麦克风可选择设备。完成后预览并另存，首次使用建议短录一段，确认画面和声音。

完整操作与故障排查见 [用户指南](docs/USER-GUIDE.md)。

## 配置 AI

AI Screen 支持兼容 **Chat Completions 图片输入格式**的服务。模型需要支持图片输入，仅支持文字的模型无法识别选区。

1. 打开服务设置，选择兼容 API 模式。
2. 填写 **API 根地址**，形如 `https://api.example.com/v1`。这是格式示例，请替换为自己的实际服务地址，**不要附加 `/chat/completions`**。
3. 填写服务商提供的 **模型名称**和自己的 **API Key**。本地免密服务可以留空 Key。
4. 点击测试连接，成功后保存设置。
5. 重新框选屏幕，使用翻译、分析或提问。

远程服务要求 HTTPS；本机 `localhost`、`127.0.0.1`、`::1` 服务允许 HTTP。服务不支持流式回复时，可以关闭流式选项后重试。

连接测试会发送内置小图片，实际 AI 操作会发送裁剪后的选区、提示词和当前会话最近的对话，可能产生服务商费用。识别效果、可处理的图片尺寸与费用取决于所配置的模型及服务。

### 离线提取文字

将文字识别方式切换为 **Windows 本地 OCR**，并确保系统安装了对应 OCR 语言组件。此时“复制文字”无需 AI Key，也不会把图片发送给 AI 服务。翻译、分析和提问仍需配置 AI。

演示模式返回模拟内容，适合体验交互，不代表真实识别结果。

## 数据与隐私

- 分发包不附带开发者的 API Key 或个人设置，每位用户自行配置服务。
- API Key 使用 Electron safeStorage / Windows 用户加密能力加密保存到当前用户的数据目录。
- 复制图片、演示模式和 Windows 本地 OCR 不向 AI 服务上传截图；AI 操作会向你配置的服务发送相应内容。
- 截图和对话默认按当前会话保留。录像会使用系统临时文件，完成后请及时另存。
- 分享程序时，不要附带自己的 `settings.json` 或应用用户数据目录；跨 Windows 账户复制设置也可能导致 Key 无法解密。

## 开发与构建

### 开发环境

- Windows x64。
- 建议使用 **Node.js 22.x，版本不低于 22.12**；项目的 `.nvmrc` 指定 Node 22。
- npm，以及可用的网络连接，用于首次下载依赖、Electron 和打包工具。
- 系统 .NET Framework 64 位编译器，用于构建原生截图助手。

获取源码后，在包含 `package.json` 的项目根目录执行：

```powershell
npm ci
npm run dev
```

构建并运行生产版本：

```powershell
npm run build
npm start
```

修改主进程、preload 或共享 IPC 契约后，请重启开发进程。

### 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm test` | 运行单元测试及本机模拟服务测试 |
| `npm run build` | 类型检查、生产构建、原生截图助手及第三方声明 |
| `npm run smoke` | 启动 Electron 做集成检查，需要可用桌面与 OCR 语言组件 |
| `npm run pack` | 生成完整的 Windows 运行目录 |
| `npm run release:win` | 测试、构建、生成安装版 / ZIP / 源码包，并解压核对与输出校验值 |
| `npm run release:zip` | 生成并核对解压版和源码包，跳过安装包制作 |
| `npm run release:check` | 核对当前版本运行目录与构建文件是否一致 |

发布产物输出到 `release/v版本号/`。已存在的同版本分发文件不会被覆盖；发布新版本前需要同步更新版本号。

仓库提供 Windows CI 和手动 / tag 触发的发布构建。发布构建会保存 Actions artifact，维护者仍需将成品添加到 GitHub Releases。

完整的打包、上传和分发流程见 [发布说明](docs/DISTRIBUTION.md)。

### 项目结构

```text
src/
  main/        Electron 主进程、系统能力和服务
  preload/     受限 IPC 桥接
  renderer/    React 界面
  shared/      共享类型、输入校验和算法
assets/        应用图标
scripts/       开发、构建与发布工具
tests/         自动化测试
docs/          使用指南、发布说明与开发记录
```

## 当前限制

- 当前为测试版，验证主要来自本机 Windows 10；Windows 11、多屏 / 混合 DPI、不同显卡和音频设备的完整兼容性仍待实机验证。
- 截图和录屏选区限制在单个显示器内；录屏范围固定，不会自动跟随窗口移动。
- 自动滚动长截图为实验功能。动态重排、动画、重复内容或重叠不足可能影响拼接，请检查输出。
- 录音受设备、权限和系统输出状态影响；长时间录制前建议先完成短录测试。
- 安装、升级、卸载与不同电脑上的使用仍需持续验证。
